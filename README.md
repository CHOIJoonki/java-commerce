# Java Commerce Platform

Java 기반 콘솔 커머스 플랫폼 프로젝트입니다.

## 프로젝트 소개

객체 지향 설계를 적용하여 상품 관리, 장바구니, 주문, 고객 등급 할인 기능을 구현한 커머스 시스템입니다.

## 기술 스택

- Java 17
- IntelliJ IDEA

## 프로젝트 구조

```
src/
├── step1/          # 기본 상품 출력
├── step2/          # CommerceSystem 클래스 분리
├── step3/          # Category, Customer 클래스 추가
├── step4/          # 캡슐화 적용 (Getter/Setter)
├── challenge1/     # 장바구니 및 주문 기능
├── challenge2/     # 관리자 모드
└── challenge3/     # Enum, 람다, 스트림 활용
```

## 주요 기능

### 필수 기능
- 상품 목록 출력 및 선택
- 카테고리별 상품 관리 (전자제품, 의류, 식품)
- 고객 정보 관리 (이름, 이메일, 등급, 누적 주문 금액)
- 캡슐화를 통한 데이터 보호

### 도전 기능
- **장바구니**: 상품 추가(수량 입력), 재고 검증, 총 금액 계산
- **주문**: 이메일 기반 고객 조회, 등급별 할인 자동 적용, 재고 차감
- **관리자 모드**: 비밀번호 인증, 상품 추가/수정/삭제
- **고객 등급 시스템**: 누적 금액에 따른 자동 등급 변경
    - BRONZE (0%) → SILVER (5%) → GOLD (10%) → PLATINUM (15%)
- **스트림 활용**: 가격대별 필터링, 상품 검색

## 실행 방법

1. IntelliJ IDEA에서 프로젝트 열기
2. JDK 17 설정
3. `challenge3/Main.java` 실행
